# Experimental native Unity World Plan slice

This Expansion-only slice uses deterministic procedural terrain and an explicitly reviewed structured plan. Prompt text is recorded context; it is not interpreted by an LLM or image-to-map model. The first verified fixture is a 256 × 256 m two-lane layout, seed 42, 129 × 129 16-bit heights, four build zones and two actual Archer Tower instances from the same project's validated Unity prefab package.

Create → Map / World prepares a plan without GPU work. Users can edit the JSON, save immutable plan versions, approve the exact plan and generator hashes, then build through the shared heavy GPU queue. UI drafts and job identity survive refresh. The original native prefab bytes/checksums are reused. Missing or cross-project props block the request; this slice creates zero child AI jobs. Editing the plan or changing generator code invalidates the previous approval. Retry preserves the effective configuration and uses a fresh native Editor project. Cancellation and timeout retain partial evidence without claiming resumable generation or success.

Actual outputs include `height.png` and little-endian `height.raw`, road/build-zone masks, procedural diffuse terrain layers, `world_plan.json`, native `TerrainData.asset`, `Navigation.asset`, prefab instances, `RunavelleWorld.unity`, real camera renders and `AFS_World.unitypackage`. A small runtime script restores the saved NavMeshData when opening the scene. Separate Unity processes build and cold-reopen the saved scene; acceptance checks terrain resolution/collider, saved prefab identity/scale, road paint at spawns and complete spawn-to-goal native NavMesh paths. A native initialization issue that reset the painted terrain layers was detected by real QA and fixed by applying alphamaps after creating the Terrain object. Failed attempts remain failed.

Export creates a checksum-verified ZIP under `Library/exports/<project-id>/<asset-id>/<export-id>/`, with named project/asset/preset folders and a manifest. It contains the native Unity package and source data; individual validated files remain accessible. Existing masters and plan versions are preserved. Master selection is separate from output artistic approval.

Verified Editor profile: **Unity 6000.4.8f1 / Built-in**. This does not validate URP/HDRP, arbitrary Unity releases or a production game. The native GPU slot remains reserved through build and cold reopen for predictable resource use. RAM measurements sum the process tree's resident sets; GPU samples are whole-device `nvidia-smi` values, including other GPU consumers, not engine-exclusive allocator peaks. See `evidence/universal_world_native.json` for actual timing, samples, outputs and desktop relaunch evidence.

Limitations: provisional terrain colors and simple diffuse noise are not an AI PBR terrain material workflow; no river/bridge/scatter/biome generator, player FPS/memory budget approval, cinematic/character work or claim of game-ready artistic quality. Unreal installation/testing is deferred at the user's request. A loaded model or passing Editor report does not establish Meshy parity. Additional Universal phases remain in the implementation ledger.

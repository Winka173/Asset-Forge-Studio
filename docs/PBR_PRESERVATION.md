# Core PBR preservation at Blender LOD0

The existing Blender worker runs the new read-only comparison after actual GLB reopen and technical inspection, before registering its processed candidate. It writes `jobs/<job-id>/output/pbr_preservation.json` and records the outcome in the orchestration manifest. A measured **Fail** fails this stage before candidate registration/automatic export; original source, Blender outputs and diagnostic report remain available. Existing SQLite workflow, scheduler and independent art status remain authoritative.

The scoped route is static, one mesh instance/triangle primitive, one explicitly bound core material, direct TEXCOORD_0 base-color and metallic/roughness maps, no extension shaders/additional normal/AO/emissive maps, vertex colors, morphs or skins. Vertex colors need separate correspondence checks; matching map pixels cannot certify them. Within the scoped route it compares decoded base-color RGBA pixels/dimensions, roughness G and metallic B pixels/dimensions, core numeric factors, alpha mode and double-sided flag. Factors allow absolute 1e-6 exporter float rounding. Alpha cutoff is compared for MASK; it has no effect in OPAQUE/BLEND. Unused metallic/roughness R/A packing is not a false loss. Files are hashed before/after measurement and the validator identity includes dependent inspectors. Images reuse the actual MIME/byte-bounds/decode/reference/declared-UV validation and its image-size limits.

**Pass** means those data survived, not that the rendered shader or asset quality is equivalent. Sampler declarations are recorded independently; Blender can replace unspecified filters with explicit LINEAR/trilinear filtering. Sampler fidelity remains **NotEvaluated**. Geometry, UV correspondence/overlap, normals, hierarchy, texel density, physical material plausibility, appearance and artistic/Meshy quality are outside this report. Duplicate UV keys in retained examples prevent a general mapping proof; matching pixels must not become that proof.

Unsupported source/target routes and explicitly requested `material_edit` return **NotEvaluated** with an explanation, never Pass. A malformed scoped input or known measured invariant loss returns Fail. Intentional edits are not a claim that all other channels were preserved. Existing generations are not relabeled as inspected, and raw/manual exports retain their existing behavior. This gate applies to newly executed Blender processing, not retroactive certification of every old asset or every export format.

The comparison uses decoded RGBA8 values. Higher-than-8-bit PNGs are explicitly NotEvaluated, so normalizing them for hashing cannot silently certify preservation of higher precision. Source files remain intact.

## Contract for the independently redesigned UI

No new queue, page or mandatory output setting is needed. `GET /api/production/assets/<id>` already returns selected versions with `artifacts[].metadata.pbr_preservation`; the related `stages[].qa.pbr_preservation` now exposes the same diagnostic, including a failure before candidate registration. The same detail powers Library. Data includes source/target SHA-256, validator identity, status/reason, independent boolean checks, measured channel hashes and explicit limits. Artifact data is version-specific. Do not present NotEvaluated as passed or change `art_review_status` from this result. A collapsed technical evidence panel can consume this object when UI work reaches that point.

## Validation scope

Unit tests use actual encoded GLB/PNG mutations: lost maps/material, changed base/Roughness/Metallic pixels, factors, alpha and sidedness fail; unused MR red/sampler changes and exporter float rounding do not fabricate loss; invalid factors fail closed; extensions/material revisions stay unevaluated. A declared worker fault test runs actual Blender on a technical box, then deliberately removes one exported material binding: the real checker fails the job, publishes no processed artifact, atomically retains the diagnostic and leaves an unrelated queued job unchanged. This is negative fault injection, not a successful generated asset.

Native acceptance is separate: current packaged CPU Blender processes both retained neural tower and castle, exports real GLBs, checks hash-bound reports through the API and disk, opens the processed model and restarts without new inference. These are retained neural sources processed anew, not new AI generation or artistic approval.

# Decisions

- 0.9.5: add measured LOD surface evidence without changing master geometry, ratios, quality lock or texture budgets. Normalize only the reported distances, never independently normalize models for comparison. Keep sampled error distinct from artistic/texture/silhouette certification. Actual bake completion alone cannot justify enabling normal/AO production processing.
- A failed Unity Package Manager IPC startup may relaunch the same Editor stage once, preserving the original failed log and exact command fingerprint. No upstream AI/Blender regeneration or quality downgrade; permanent content/license failures remain visible.

- The 2026-10-22 Adaptive 3D Production + AI Quality Control user specification supersedes the prior proposal of adding mandatory VLM gates everywhere.
- Technical/mandatory structural validation is authoritative; uncertain aesthetic observations are advisory in Auto. Never turn uncertainty into artistic approval.
- Reuse the existing coordinator, SQLite, scheduler, status dimensions, Library and revision/export transactions.
- Diagnose each failed stage from actual logs before changing engines. Repeating a missing dependency with a new seed is not recovery.
- Architecture may use verified parametric geometry when it satisfies declared requirements; do not force all architecture into Blender or downgrade a required photoreal/AI-textured/exact-image route.
- Image interpretation and geometry planning are separated so a style reference cannot silently become the target object. Their results remain inferred and reviewable.
- Keep user Library untouched during acceptance. No unrelated Video/Audio expansion work in this task.
- Retain the real historical tower as a hash-bound regression baseline. A shape-reference request always retains image-to-3D; the narrow authored castle route is not an artistic quality replacement. Replays use explicit original settings and separate output directories. Never lower quality to clear a queue/resource failure.
- Permanent admission/delivery exceptions stop repeated polling retries for that asset until explicit Retry; manual approval checkpoints remain separately reevaluated. Quarantined queued stages and terminal concept blockers do not reserve the logical asset window.

- 2026-10-23: Text routes generate a concept tournament (Maximum 3, Balanced 2, Fast 1; per-item `concept_candidates` override) and rank only eligible concepts (cropped/too-small concepts are never promoted). User-provided references are not ranked or gated. Project style anchors use IP-Adapter Plus SDXL at 0.35 by default; the anchor identity and scale are locked in the effective configuration.

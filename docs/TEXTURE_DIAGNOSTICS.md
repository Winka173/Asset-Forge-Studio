# Embedded texture integrity

The GLB inspector validates embedded PNG/JPEG image byte ranges, MIME/signature agreement, full image decoding, texture/image/sampler references and declared UV accessor shape/count. Loaded nonfinite UVs reject inspection. It records actual dimensions, encoded bytes/hash, decoded RGBA pixel hash, material bindings and packed metallic/roughness channel meanings. No image is resized, sharpened, repainted or generated. Existing image-free constant materials remain valid and report no maps.

The container reader retains JSON and BIN offsets rather than a second full BIN allocation. Images decode one at a time; pixel hashing uses 64-row strips. The supported per-image budget is 67,108,864 pixels (8192 squared) and 256 MiB encoded. This is an explicit inspection limit, not a lower generation-quality setting. Larger or non-core image formats need a separately validated route. References: [Khronos glTF 2.0 images](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#images), [materials](https://registry.khronos.org/glTF/specs/2.0/glTF-2.0.html#materials).

Library, Production and Compare expose collapsed artifact-specific texture evidence. Existing versions can use **Inspect selected model**, reusing the existing Library inspection action. This reads a selected GLB without AI/Blender regeneration, stores a separate hash-bound inspection and overlays evidence only for that matching version. Failed checks show an error. Concurrent worker master/publication/history updates are retained under the existing write lock. Source artifacts and other versions are not edited. It does not change artistic approval or certify automatic technical remediation.

New imports, processed GLBs and exports run the same inspector. Export manifests already include the actual QA report, so no new mandatory output or manifest-format replacement is required. Re-export does not rerun inference. Technical QA cache identities include the dependent inspection modules so a changed validator cannot silently reuse its own earlier pass.

Image decoding and resolution are technical evidence, not visual quality, texel-density, UV-overlap, PBR plausibility, shader-parity or Meshy certification. Missing normal/AO channels are not fabricated. Historical measurements are not relabeled as newly tested until an actual inspection runs.
